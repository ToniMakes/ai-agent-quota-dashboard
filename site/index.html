Local-first by design

The public page is only the download door.

AIQD still runs on your own machine. The desktop app starts a local service on 127.0.0.1, reads narrow quota-related local files from tools you already use, and renders the dashboard locally.

Codex CLI

Reads supported local rate_limits events when Codex writes them, with a visible-status manual fallback.

Claude Desktop

Reads local plan usage samples from Claude Desktop. No Claude Code CLI setup is required for desktop-only users.

Claude Code CLI

Captures official statusline rate_limits fields through an explicit local setup step.

Privacy boundary

No prompts, code, cookies, or passwords.

  • Runs locally and serves the dashboard through localhost.
  • Stores normalized quota snapshots in local SQLite.
  • Does not upload prompts, responses, source code, or chat content.
  • Does not read browser cookies, simulate login, or call hidden APIs.
