# Code of Conduct

This project should be a focused, respectful place to build a privacy-first developer tool.

## Expected Behavior

- Be kind and precise.
- Assume good intent, but ask for evidence when data reliability matters.
- Keep discussions technical and grounded in sources.
- Respect privacy boundaries.
- Help contributors sanitize examples and fixtures.

## Unacceptable Behavior

- Harassment, threats, or personal attacks
- Publishing private or sensitive data
- Pressuring maintainers to support non-compliant data sources
- Encouraging credential capture, hidden API use, login simulation, or rate-limit bypassing

## Enforcement

Maintainers may edit, hide, or remove comments, issues, pull requests, or contributions that violate this code of conduct or the project's privacy boundaries.
