# Code Signing Policy

Last updated: 2026-08-25

AI Agent Quota Dashboard uses an installer-first release path for Windows preview builds. The preferred signing path for the first formal desktop preview is SignPath Foundation open-source code signing.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

## Release Intent

The preferred path is a signed Windows installer. SignPath Foundation approval was still pending on 2026-08-25, so the maintainer explicitly approved publishing `v0.1.0` as an unsigned desktop preview instead of blocking the first release.

Unsigned public artifacts must be clearly labeled as unsigned in the GitHub Release notes and README. The release notes must include the final SHA256 and warn that Windows may show an unknown-publisher or SmartScreen prompt.

## Signing Scope

The signed artifact is the Windows x64 NSIS installer generated by `electron-builder`:

```text
AI Agent Quota Dashboard-0.1.0-win-x64.exe
```

Release signing must use artifacts built from this repository by GitHub Actions. Maintainers should not upload locally built binaries for release signing with the SignPath Foundation certificate.

## Build Origin

Release candidates and signed release artifacts are built through GitHub Actions from the public source repository:

```text
https://github.com/isToniLiu/ai-agent-quota-dashboard
```

The Windows package workflow builds the app, runs the local test gate, uploads the unsigned installer as a GitHub Actions artifact, and can submit that artifact to SignPath after the project is approved and the required SignPath secrets/variables are configured.

## Roles

- Committer and reviewer: [Toni Liu](https://github.com/isToniLiu), repository maintainer
- Signing approver: [Toni Liu](https://github.com/isToniLiu), repository maintainer

All maintainers with source repository or SignPath access must use multi-factor authentication.

## Artifact Metadata

Signed Windows artifacts should enforce these metadata values:

- Product name: `AI Agent Quota Dashboard`
- Product version: the version in `package.json`
- Package type: Windows x64 NSIS installer
- Repository origin: `https://github.com/isToniLiu/ai-agent-quota-dashboard`

## Privacy

AIQD is local-first. It reads narrow local quota-related files from tools the user already runs and serves normalized data through `127.0.0.1`.

AIQD does not upload prompts, responses, source code, chat content, credentials, cookies, session tokens, or raw local logs.

See [Privacy](privacy.md) for the full privacy boundary.

## System Changes

The Windows installer creates normal per-user application entries and shortcuts through NSIS. Launch at login is opt-in, defaults off, and can be changed later from Settings.

The uninstaller removes AIQD-owned startup entries. Startup behavior is documented in [Distribution and Startup](distribution.md).

## Verification

Before publishing a signed installer in a later follow-up release:

1. Run the release checklist in [Release Checklist](release-checklist.md).
2. Build the Windows installer through GitHub Actions.
3. Submit the GitHub Actions artifact to SignPath.
4. Manually approve the signing request in SignPath.
5. Download the signed artifact from the workflow.
6. Verify the Windows Authenticode signature reports `Valid`.
7. Upload the verified signed installer to a new follow-up GitHub Release. Do not silently replace the `v0.1.0` unsigned installer asset.

On Windows, verify the final artifact with:

```powershell
Get-AuthenticodeSignature ".\AI Agent Quota Dashboard-0.1.0-win-x64.exe"
```
