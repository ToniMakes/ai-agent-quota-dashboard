# App Icon Assets

`icon.svg` is the source app icon. `tray-icon.svg` is the source tray icon, with the same mark enlarged on a transparent background for small notification-area sizes.

Run `npm run icons:generate` to refresh the PNG and ICO outputs used by the desktop shell, tray, and Windows shortcuts.

The mark combines a quota ring, a reset/usage arc, and a Q-shaped tail. Keep it readable at tray size before changing the detail level.
